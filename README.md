# ДЗ №4 — автотесты генератора квизов

Пять UI-тестов на TypeScript и Playwright с паттерном Page Object.
Проверяют [генератор квизов](https://p-vlasenko.github.io/higher-web-practice-quiz-generator/),
размещённый на GitHub Pages. Для запуска нужен интернет.

## Установка

Понадобятся Node.js **26.13.0** и pnpm **10.20.0**.
Команды выполняются из корня репозитория.

Если используете fnm, установите его и подключите к своей оболочке.
Затем выберите версию Node.js из `.nvmrc`:

```bash
fnm install
fnm use
```

Установите pnpm, зависимости проекта и браузер Chromium:

```bash
npm install --global pnpm@10.20.0
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
```

Если на Linux браузеру не хватает системных библиотек:

```bash
pnpm exec playwright install --with-deps chromium
```

## Запуск

Запустить все пять тестов:

```bash
pnpm test
```

Чтобы видеть действия в браузере, используйте `pnpm test --headed`.
Собирать проект или запускать локальный сервер не требуется.

Другие команды:

| Команда | Что делает |
| --- | --- |
| `pnpm check` | Проверяет типы, запускает ESLint и тесты |
| `pnpm typecheck` | Проверяет типы TypeScript |
| `pnpm lint` | Проверяет код через ESLint |
| `pnpm test --repeat-each=3` | Запускает каждый тест три раза |
| `pnpm exec playwright show-report` | Открывает отчёт последнего запуска |

При падении теста скриншот и трассировка сохраняются в `test-results/`.
HTML-отчёт находится в `playwright-report/`.

## Что проверяют тесты

- **Генератор:** ошибки при некорректном JSON и отсутствии названия квиза,
  закрытие окна ошибки.
- **Список квизов:** созданный квиз отображается и сохраняется после перезагрузки.
- **Прохождение:** правильные ответы с одиночным и множественным выбором дают
  максимальный результат; ошибка показывает пояснение и учитывается в результате.

Сценарии находятся в [tests/quiz.spec.ts](tests/quiz.spec.ts), тестовые данные —
в [tests/data/quiz.ts](tests/data/quiz.ts). Работа со страницами вынесена
в [tests/pages/](tests/pages/): там хранятся локаторы, действия и проверки.
Каждый тест запускается в отдельном контексте браузера и сам создаёт свои данные.
